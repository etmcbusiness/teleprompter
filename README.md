# Prompter

A simple teleprompter web app for iPhone. Upload a Word `.docx`, and the text scrolls up slowly.

- Adjustable speed and text size (remembered between uses)
- Sections are detected from Word headings, short bold lines, lines like "Section 2" / "Part 3" / "Scene 1", `[Label]` lines, `# Heading` lines, and divider lines (`---`, `***`)
- Jump between sections, tap the text to play/pause, drag to scrub, mirror mode
- Keeps the screen awake while playing; works offline after the first visit

**Install on iPhone:** open the site in Safari → Share → Add to Home Screen.
